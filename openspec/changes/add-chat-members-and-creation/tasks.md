Each task names the files it owns and what it depends on. Tasks without a dependency between them may run in parallel; a task shares files with every task that edits the same file, so those run in order. Tasks marked `[approval]` act on the real account and need the user's explicit approval of the target before they start; without it they stay open and block only the archive, not the implementation.
