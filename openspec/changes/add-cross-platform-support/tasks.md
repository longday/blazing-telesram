# Tasks: add-cross-platform-support

Legend. **[vm]** a check in a VM per `docs/vm.md` (own `~/bt/src-<name>`, removed afterwards; the Linux checks need the VM of 0.1). **[live]** needs the signed-in session and the real account (one live slot at a time, rule 5; reads only). **[needs-user]** needs the user or the user's hardware (a real Windows or Linux desktop, a go-ahead). **[code]** changes source. **[spike]** writes only the results table of `research.md`. Merge-unit tags: **XP-A** storage and names (libraries only), **XP-D** desktop neutral parts, **XP-S** sign-in helper, **XP-P** voice, **XP-W** Linux window chrome, **XP-N** notifications, **XP-B** badges, **XP-V** docs and final checks. A task stops holding its files once it is merged into `integ/cross-platform` (rule 1 of `DEPENDENCIES.md`); a task that has not started locks nothing (rule 6).

Gate per unit, in `bt-vm`: `cargo fmt --all --check`; `cargo build --workspace --all-targets --locked` 0 warnings; `cargo test --workspace --locked` (the existing counts plus the new tests, none removed); `cargo clippy --workspace --all-targets --locked` no new warning over the 10-warning baseline; `openspec validate add-cross-platform-support --strict`. From XP-A on, additionally the cross-target check of 1.7 (and, once the desktop is whole, 8.2).
