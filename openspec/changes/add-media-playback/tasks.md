# Tasks

Legend: **[live]** needs the signed-in session in the VM's `~/bt/.runtime` and the real account; every live task here is **reads only with the app account and needs no user** (see `research.md`); live tasks share the one live slot (`DEPENDENCIES.md` rule 5), `BT_WRITE_ONLY_CHAT` stays set. **[blocked: 0.x]** waits for that research task; if the research cannot run, the default in `research.md` ("What each unknown decides") applies and the task says so in its result. A blocked task is not started until the block is lifted.

Contracts (types, names, selectors, labels) are fixed in `design.md` D2-D8, so tasks can be coded against them in parallel. Each task names the files it owns; `DEPENDENCIES.md` rules apply: one owner per file at task granularity, every merge to `main` compiles and passes tests with no stubs and no no-op arms (rule 2), **zero build warnings** and no `#[allow(dead_code)]` (rule 3), cargo, `bt-probe` and the app only in the Tart VM `bt-vm` in the agent's own `~/bt/src-<name>` (rule 4, `docs/vm.md`). Unit tests belong to the task that adds the code, except the shared `desktop/src/tests.rs` (5.6, 5.8).

Merge units: **PB-V** (voice) = 1.1, 1.2, 2.1, 2.2, 3.1, 4.1, 4.2, 5.1, 5.2, 5.3, 5.5, 5.6 on branch `integ/add-media-playback`; **PB-W** (video) = 1.3, 2.3, 3.2, 5.4, 5.7, 5.8, started after PB-V is on `main` (it extends files PB-V holds). Checks per unit in `bt-vm`: `cargo build --workspace --all-targets --locked` with zero warnings, `cargo test --workspace --locked`, `cargo clippy --workspace --all-targets --locked` (no new warning over the baseline in `DEPENDENCIES.md`), `cargo fmt --all --check`, `openspec validate add-media-playback --strict`.
